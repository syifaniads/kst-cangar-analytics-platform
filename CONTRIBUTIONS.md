## Why this repository is separate

The original repository contains a complete WordPress installation, WordPress core files, default themes/plugins, uploaded assets, and team-wide implementation. For a portfolio reviewer, that makes it difficult to distinguish the engineering contribution that is most relevant to my work.

This repository therefore acts as a **curated case study** rather than a misleading duplicate of the full team repository. It provides:

- contribution evidence,
- implementation screenshots,
- system architecture,
- integration notes,
- testing and limitations,
- direct links back to original code and commits.
